# Agent policy

Read, in order:

1. `DoWork.txt`
2. `engineering/control-plane.json`
3. `docs/EXECUTION_AUTHORITY.md`

Then read only the repository-local and specialist documents required by the current task.

This repository coordinates product repositories; it does not replace their governing documents. Product-repository authority remains binding whenever product code or Product Reality is involved.

Never infer missing GitHub state, invent Product Reality, invent percent complete, merge red/pending/conflicted/uncertain code, bypass repository-native preflight/CI/review, create competing ownership, disable DoWork, or commit secrets/private Product Reality payloads.

Specialist mechanisms are activated on demand through the reference map in `docs/EXECUTION_AUTHORITY.md`. Do not preload every specialist policy into every session.

Prefer small deterministic changes with regression protection. Re-read current-head review evidence immediately before merge.
