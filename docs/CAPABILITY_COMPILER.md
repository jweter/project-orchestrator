# Daedalus Capability Compiler v1

The compiler closes the verified engineering-learning loop without creating a competing authority.

## Five abilities

1. Capture sanitized VERIFIED repair/experiment episodes with deterministic identities.
2. Fingerprint recurring failures per product repository.
3. Compile only repeated, matching VERIFIED episodes into advisory executable capability rules.
4. Inject repository/fingerprint-applicable capabilities into scheduler packets before worker dispatch.
5. Measure VERIFIED reuse outcomes, promote consistently successful rules to PREFERRED, and immediately DEMOTE a rule when verified regression evidence appears.

All compiled rules remain advisory. They cannot weaken repository gates, merge, alter Product Reality truth, expand privacy/security/licensing authority, or turn historical narrative into verified evidence.

## Historical seed policy

`engineering/capability-compiler-seeds.json` contains the real failure/success classes already encountered across all five product repositories. Historical seeds are intentionally marked `HISTORICAL_SEED_PENDING_LIVE_REVALIDATION`; the compiler accepts only `VERIFIED` episodes. Live exact-head/CI/worker evidence must therefore revalidate a seed before it can become executable retained policy.

This prevents the bootstrap process from laundering remembered state into authority while still giving Daedalus concrete real-world candidates to learn from.
